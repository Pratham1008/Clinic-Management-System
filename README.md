# 🏥 Clinic Management System

A full-stack **patient-doctor portal** built with **Flutter** and **Spring Boot**, featuring secure authentication, role-based access, appointment management, and real-time notifications.

## 🚀 Features

- 🧑‍⚕️ Role-based login system for Admin, Doctors, and Patients
- 🔐 JWT-based authentication and secure APIs
- 📅 Appointment booking and schedule management
- 📊 Dashboards for patients and doctors
- 📬 Firebase push notifications
- 🐳 Dockerized backend for easy deployment

## 🛠 Tech Stack

**Frontend:**  
- Flutter  

**Backend:**  
- Java  
- Spring Boot  
- PostgreSQL  
- Firebase Admin SDK  
- JWT Auth

**DevOps & Deployment:**  
- Docker  
- Render (for deployment)
